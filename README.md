# Цифровой механик

AI-агент предиктивной диагностики ДВС коммерческого транспорта. Хакатон «ИИкузница»,
трек «Цифровой механик» (заказчик — ООО «НейроДВС»), 26–28.11.2026.

Агент получает результат акустической проверки из Mock ML API, объясняет его механику,
ищет процедуры и нормативы в руководствах по ремонту (с указанием документа и страницы PDF)
и формирует заявку на дефектовку в Mock ТОиР.

> Статус: в разработке. Готовы каркас репозитория и поисковый индекс по руководствам.
> Интерфейс и агент — в работе.

## Архитектура

```
React + Vite  ──HTTP/SSE──  FastAPI
                              ├─ агент (tool calling): diagnose | search_manuals |
                              │   vehicle_history | fleet_overview | create_ticket
                              ├─ RAG: BM25 + фильтр по модели двигателя,
                              │   чанки с doc_id и номером страницы PDF
                              ├─ SQLite: проверки, заявки, история диалогов
                              └─ Mock ML / Mock ТОиР (адреса из .env)
```

## Быстрый старт (поиск по руководствам)

Нужен Python 3.11+ и [`uv`](https://docs.astral.sh/uv/).

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r backend/requirements.txt

# PDF руководств в репозиторий не входят. Положите их в manuals/
# (имена файлов — см. backend/app/rag/manuals.py).

.venv/bin/python backend/scripts/ingest.py
.venv/bin/python backend/scripts/search.py \
  "момент затяжки крышек коренных подшипников" --engine ЯМЗ-236М2
```

Индекс собирается за ~10 секунд: 6 руководств, 1743 страницы, ~3500 чанков.

## Структура

```
backend/app/rag/       извлечение PDF, нарезка, BM25-индекс, реестр руководств
backend/scripts/       ingest.py, search.py
data/                  vehicles.json и fault_types.json (синтетика заказчика)
manuals/               PDF руководств (в .gitignore, в репозиторий не попадают)
```

## Данные

`data/vehicles.json` и `data/fault_types.json` — синтетические материалы хакатона,
предоставленные заказчиком. Реальных записей и данных автопарков в репозитории нет.
PDF руководств являются собственностью правообладателей и в репозиторий не включены.
